## 🔁 How to Set This Project Up with GitHub Desktop

Want to link an existing local folder (like `11.react`) to GitHub without renaming it? Here’s how:

### ✅ Step 1: Initialize Git in the Folder

```bash
cd "E:\TATA STRIVE\CODECADEMY\11.react"
git init
````

---

### ✅ Step 2: Add the Folder to GitHub Desktop

1. Open **GitHub Desktop**
2. Go to **File → Add Local Repository**
3. Choose this path:

   ```
   E:\TATA STRIVE\CODECADEMY\11.react
   ```
4. Click **Add Repository**

---

### ✅ Step 3: Make Your First Commit

1. In the **Changes** tab, write a summary:

   ```
   Initial commit with React core files
   ```
2. Click **Commit to main**

---

### ✅ Step 4: Publish to GitHub

1. Click **Publish repository**
2. Set the name to: `react`
3. Choose Public or Private
4. Click **Publish Repository**

---

### ✅ Final Outcome

* Local folder: `11.react` ✅ (unchanged)
* Remote GitHub repository: `react` ✅
* Version-controlled and online!
